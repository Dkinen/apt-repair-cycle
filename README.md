# apt-repair-cycle
공동주택 장기수선 주기 실증 분석 (대학 캡스톤 연구, 비영리)

[목적]
공동주택 장기수선계획은 법령 별표의 수선주기를 그대로 적용해 수립되지만, 이 주기가 실제 교체 시점과 맞는지 전국 단위로 검증된 적이 거의 없습니다. 본 연구는 공동주택관리정보시스템에 공개된 유지관리 이력을 이용해 부위별 실제 교체 주기를 추정하고 법령 주기와 비교합니다.

[주요 기능]
1. 데이터 수집: 단지코드별로 유지관리 이력(건물외부, 전기/소화/승강기)을 조회해 공사종별·수선방법·공사완료일을 수집합니다.
2. 정제: 공사종별을 분석 부위(승강기 기계장치, 지붕 방수, 외부 도장)로 매핑하고 전면교체 여부를 판정합니다.
3. 분석: 생존분석(Kaplan–Meier, Cox 비례위험모형)으로 아직 교체하지 않은 단지까지 반영해 부위별 수선주기를 추정하고, 준공연도·세대수·난방방식·지역에 따른 차이를 분석합니다.
4. 결과 제공: 부위별 교체 생존곡선, 법령 주기 대비 편차표, 30년 수선비와 장기수선충당금 부족 위험을 보여주는 대시보드(웹)를 제공합니다.

[화면 구성]
- 부위별 생존곡선과 95% 신뢰구간, 법령 수선주기 기준선
- 법령 주기 vs 실측 추정 주기 비교표
- 30년 누적 수선비 전망과 충당금 부족액 진단

[호출량 산정]
전국 의무관리대상 공동주택 약 2만 단지 × 2개 기능(건물외부, 전기/소화/승강기) = 약 4만 건. 1회 전수 수집 후 월 1회 갱신 예정이며, 요청 간격을 두고 호출합니다.

[데이터 취급]
결과는 준공연도대·지역 등 집계 단위로만 공개하며, 개별 단지는 식별되지 않도록 익명 처리합니다.
